# Lexora 采集进度

原生 macOS 菜单栏小工具，通过 Cloudflare 中转只读查询两台 Lexora
词库服务器并分别显示全量采集进度与高频 20,000 极速词库的质量进度。

- 菜单栏同时显示全量进度和 `20k` 质量合格率。
- 弹窗显示两台服务器各自的数量、条目状态、缺失字段和待处理示例。
- `20k` 只有在全部条目通过质量门禁后才会显示“可打包”。
- 点击“刷新”立即从 `dict.12323456.xyz` 读取两台服务器的汇总进度。
- 全量快照每 5 分钟更新；较重的 `20k` 质量审计每 60 分钟以最低优先级更新。
- 应用每 10 分钟自动刷新，并保留上次成功结果。
- 不再依赖本机 SSH、私钥或 OneDrive 路径。

构建并安装到 `~/Applications`：

```bash
zsh tool/lexicon-progress-monitor/build_app.sh
```
